## 边界

- **收**：影像器材、音频硬件、嵌入式、无线电/自建、复古计算、开源自制、语言工具、安全学习、数字化制造、精密机械、光学测量、引擎模组、数据地图技术、飞控、印刷字型等

- **不收主轴**：纯运动、纯美食、纯旅游攻略
