# 表演与舞台

词表大类。21 片叶子：台上练的、广场跳的、茶馆说的、话筒后的。

这里不写「京剧史」「舞蹈分类学」。写的是人怎么进票房清唱、怎么在开放麦试五分钟新稿、怎么在公园跟队。重叠很正常——跳拉丁的人也去摩登厅，单口和相声常抢同一块开放麦。遇到跨界，叶子页会互相指一下。
