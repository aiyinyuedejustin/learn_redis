# 魔术杂技

表演与舞台下的手上和身上亚类。2 片叶子：骗眼睛的，和跟重力较劲的。

## 边界

- **[变魔术](变魔术.md)**：近景扑克硬币、舞台节目、理论。圈子守秘，这页**不写手法揭秘**。
- **[练杂技](练杂技.md)**：柔术、平衡、抛接。业余班比魔术少，安全比花样重要。

两片都会上晚会，训练完全不同：魔术在镜子前磨手法，杂技在垫子上磨力量。街头表演是出口，不是入门课。

## 叶子

1. [变魔术](变魔术.md)
2. [练杂技](练杂技.md)

线上常见落点：魔术师协会、魔术吧（谈表演不谈拆解）、杂技团业余班招生。线下是魔术聚会、近景桌、柔术/空中工作室——具体群名会变，守秘和护具这两条比较稳。
