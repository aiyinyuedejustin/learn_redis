# 演说

表演与舞台下的话筒亚类。3 片叶子：对着人说、对着对手说、对着话筒演。

## 边界

- **[演讲练习](演讲练习.md)** 是公众演讲：结构、时间、评估。吐司大师（Toastmasters）分会是公开入口，不是「口才速成班」。
- **[辩论赛](辩论赛.md)** 是赛制：议会制、美式、亚洲议会。高校辩论社和公开赛是主场，电视辩论秀不是日常练习。
- **[配音爱好](配音爱好.md)** 是业余配音和广播剧：干声、对口型、后期。想当明星 CV 是另一条路；这片叶子是棚里对稿。

三片都练嘴，圈子不太掺：演讲俱乐部少谈赛制，辩手少谈广播剧音色，配音组不一定上台。

## 叶子

1. [演讲练习](演讲练习.md)
2. [辩论赛](辩论赛.md)
3. [配音爱好](配音爱好.md)

线上常见落点：演讲协会/Toastmasters 分会信息、高校辩论社招新、配音吧和有声创作社。线下是俱乐部例会、公开赛评委席后的热身、录音棚拼团——场所会变，练习节奏比较稳。
