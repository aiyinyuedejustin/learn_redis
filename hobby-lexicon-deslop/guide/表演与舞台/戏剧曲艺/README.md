# 戏剧曲艺

表演与舞台下的台上说话亚类。6 片叶子：票友两片，喜剧三片，话剧一片。都按爱好写，不按角儿和编剧岗位写。

## 边界

戏曲两片，别混成一个「听戏」：

- **[京剧票友](京剧票友.md)**：皮黄、行当、票房清唱和彩唱。
- **[昆曲票友](昆曲票友.md)**：水磨调、拍曲、曲社。南昆北昆都算，不和京剧票房抢同一口嗓。

喜剧三片，开放麦会撞车，玩法不同：

- **[单口喜剧](单口喜剧.md)**：一个人、一支麦、一段打磨过的稿。
- **[即兴喜剧](即兴喜剧.md)**：没稿，工作坊和长短游戏。
- **[说相声](说相声.md)**：捧逗、贯口、传统段和开放麦新活。

**[戏剧表演](戏剧表演.md)** 是业余话剧：读本、排练厅、小剧场。看孟京辉和自己上台是两回事，这片叶子是后者。
