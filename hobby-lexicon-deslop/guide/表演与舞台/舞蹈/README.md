# 舞蹈

表演与舞台下的身体亚类。9 片叶子，都是「自己下场跳」，不是「研究舞种源流」。

## 边界（避免看成百科词条）

- **[练中国古典舞](练中国古典舞.md)** 走身韵和剧目，和戏曲水袖有亲戚，但课堂口径是舞院教材。
- **[跳民族舞](跳民族舞.md)** 是藏、蒙、傣、维、朝鲜等民间舞组合；和古典舞常在同一家培训，圈子不全是一拨人。
- **[练芭蕾](练芭蕾.md)** 管把杆和基训；少儿考级家长群不是这片叶子的主场。
- **[跳拉丁舞](跳拉丁舞.md)** 和 **[跳摩登舞](跳摩登舞.md)** 合称国标，常在同一家舞校分厅：拉丁更胯，摩登更架。
- **[跳广场舞](跳广场舞.md)** 是公园音响和队形，不是舞厅社交舞，也不是西方 square dance。
- **[跳街舞](跳街舞.md)** 管 Hip-hop、breaking、popping 等；K-pop 翻跳会串门，Battle 圈不一定认。
- **[跳肚皮舞](跳肚皮舞.md)** 是东方舞律动；**[练钢管舞](练钢管舞.md)** 是成人向力量舞，按工作室和 pole sport 写，不按夜店写。
