# 山地户外

走路、过夜、攀、找点、沿溪。6 片叶子。词表里的「户外」在这里，不在公路跑和球馆。

## 边界

- **[徒步](徒步.md)** 当天山径、轻装；**[登山](登山.md)** 更高、更技术，绳索、冰雪、海拔反应会进讨论。
- **[露营](露营.md)** 核心是过夜和营地规矩，可以跟徒步拼线，圈子却在聊帐篷和炉头。
- **[攀岩](攀岩.md)** 岩馆抱石和线路是国内主场；户外多绳另算一档。
- **[定向越野](定向越野.md)** 地图指北针打卡，不是「跟着领队走」。
- **[溯溪](溯溪.md)** 沿溪上溯、瀑布，安全门槛高于普通徒步，别跟溪边野餐混。

和 [越野跑](../路跑与田径/越野跑.md) 常走同一条山，但越野跑按配速和补给聊，这里按路线、装备和过夜聊。
