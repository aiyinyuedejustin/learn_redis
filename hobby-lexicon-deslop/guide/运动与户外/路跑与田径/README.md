# 路跑与田径

四片叶子，全是跑，但不是同一圈人。

## 边界

- **[跑步](跑步.md)** 最宽：路跑、操场、慢跑入门、跑团夜跑。还没决定要不要报名，先落这里。
- **[跑马拉松](跑马拉松.md)** 半马全马，PB、配速、抽签、补给站。
- **[跑超马](跑超马.md)** 五十公里以上，吃睡和掉速；和全马完赛不是自动升级。
- **[越野跑](越野跑.md)** 山野小径、爬升、越野鞋，赛事轴常挂 UTMB 积分一类——和柏油马分群。

铁三里的跑见 [练铁人三项](../其他运动/练铁人三项.md)。山径走路不配速见 [徒步](../山地户外/徒步.md)。

## 叶子
