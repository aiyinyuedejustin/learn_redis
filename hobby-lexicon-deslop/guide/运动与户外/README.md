# 运动与户外

词表大类。71 片叶子：球场约球、武馆功课、下水、上山、上路，再加上力量房和靶场。

这里不写「足球史」「武术源流」。写的是人怎么约上一场业余局、怎么在岩馆刷一条 V 级、跑团夜里聊什么配速。重叠很正常——铁三的人同时在游泳和公路车圈子晃，越野跑和徒步常是同一条山径。遇到跨界，叶子页会互相指一下。
