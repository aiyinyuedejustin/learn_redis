# 射击射箭

靶场两片叶子。只写**合法、持证、在合规场地**的运动，不写枪支私藏、改装、狩猎违法情形。

## 边界

- **[射箭](射箭.md)** 反曲弓、复合弓，射箭馆就能练，国内入口比射击宽。
- **[射击运动](射击运动.md)** 气步枪/气手枪、靶场课，按当地法规和俱乐部资质来。词表口径是气枪靶场运动，不是影视枪械。

两片都聊姿势、瞄点和分组，不聊「哪里能买真枪」。

## 叶子

1. [射击运动](射击运动.md)
2. [射箭](射箭.md)
