# 力量体能

健身房三条线。3 片叶子，都在杠铃附近，目标不是一回事。

## 边界

- **[去健身](去健身.md)** 最宽：力量、体能、训练日志，还没选定专项。
- **[练力量举](练力量举.md)** 深蹲、卧推、硬拉，重量和三项合计。
- **[练健美](练健美.md)** 围度和外形，饮食和备赛比「今晚拉多少」更常聊。

奥举（抓举挺举）词表里没有单独叶子，有人从力量举馆串过去。私教上岗、职业选手不在范围内。

## 叶子

1. [去健身](去健身.md)
2. [练健美](练健美.md)
3. [练力量举](练力量举.md)

线上常见落点：健身吧、训练日志圈、力量举协会通知。线下是商业健身房、杠铃馆、健美备赛圈——先把动作做标准，再加片。
