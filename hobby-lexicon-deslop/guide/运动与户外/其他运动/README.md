# 其他运动

装不进球类、武馆、水上、山地、轮子、路跑的 8 片。彼此几乎不重叠，只是词表放在同一筐。

## 边界

- **[玩飞盘](玩飞盘.md)** 极限飞盘（ultimate）约局是主轴，公园抛盘是入门。
- **[练铁人三项](练铁人三项.md)** 泳骑跑叠在一起，单项见游泳、自行车、跑步叶子。
- **[学马术](学马术.md)** 马场课和马匹护理，不是动物园骑马照相。
- **[放风筝](放风筝.md)** 传统沙燕和特技双线；潍坊是节，不是唯一玩法。
- **[抖空竹](抖空竹.md)** 公园抖活；**[玩悠悠球](玩悠悠球.md)** 是溜溜球花式，英文 yo-yo，别和空竹的「空竹也称 Chinese yo-yo」搅成一件器材。
- **[踢毽子](踢毽子.md)** 花式踢毽；有网、有队的是 [打毽球](../球类/打毽球.md)。
- **[跳绳](跳绳.md)** 花式和耐力，一根绳，常跟体能交叉。
