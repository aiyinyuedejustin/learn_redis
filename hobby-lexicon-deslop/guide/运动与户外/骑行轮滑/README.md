# 骑行轮滑

轮子和板子。5 片叶子：公路车、山地车、滑板、轮滑、跑酷。跑酷没有轮，但词表放在这一筐——城市障碍、公共空间。

## 边界

- **[自行车骑行](自行车骑行.md)** 公路、通勤、车友拉练；**[山地自行车](山地自行车.md)** 林道、避震、下坡，车不是同一辆。
- 铁三里的骑也是自行车，专项训练见 [练铁人三项](../其他运动/练铁人三项.md)。
- **[玩滑板](玩滑板.md)** 板场和街头；**[玩轮滑](玩轮滑.md)** 直排刷街或速滑，鞋和板不是一套装备。
- **[跑酷](跑酷.md)** 跑跳翻越，训练场和城市障碍，和滑板场常共用一块水泥地。

线上常见落点：骑行吧、山地车吧、滑板吧、各地夜骑群。线下是车店局、板场、轮滑协会、跑酷训练馆——头盔在这几片叶子里都不是「矫情」。
