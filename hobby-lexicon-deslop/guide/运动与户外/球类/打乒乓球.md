# 打乒乓球

`运动与户外/球类/打乒乓球` · Table tennis

词表种子：业余对打与发球练习。馆和约球密度接近 [打羽毛球](打羽毛球.md)，球台比场地好找。

## 这是什么（人话）

一张台、一支拍，对打、发球、搓球。社区水泥台和球馆专业台都有人泡。叶子是下场练手感，不是看国家队。直拍横拍、正胶反胶，圈子里会问「你什么胶」，比问「你看不看球」更早。

## 怎么玩 / 圈子里聊什么

- 发球：下旋侧旋，接发球搓还是挑。
- 正胶、反胶、长胶；胶皮海绵厚度。
- 直拍横拍，弧圈还是近台快攻。
- 业余联赛积分、让分，以及「这球出台没有」。

乒协、业余联赛、球馆是主场。线下是社区球台、单位活动室、市区乒乓球馆。馆里常按水平分桌，新手桌和「杀球桌」别坐错。

## 入门线索

- 线上：乒协通知、业余联赛报名、球馆约球群。
- 线下：社区球台、球馆包桌、单位联谊赛。
- 起点：借拍先对打和发球，胶皮等手感稳了再换。别一上来就买赛级底板。
