# 球类

运动与户外下最大的亚类。17 片叶子，都是「下场打」，不是「看球评球」。看球可以当入口，叶子本身是业余对打和联赛。

## 边界

大球和小球别混成一个「球类爱好」：

- **[业余足球](业余足球.md)** / **[业余篮球](业余篮球.md)** / **[业余排球](业余排球.md)**：人多、场地好找，约球群是主场。
- **[业余棒球](业余棒球.md)** / **[业余垒球](业余垒球.md)** / **[业余橄榄球](业余橄榄球.md)**：国内场子少，俱乐部制更明显。垒球慢投和棒球不是同一套规则。
- **[打羽毛球](打羽毛球.md)** / **[打乒乓球](打乒乓球.md)** / **[打网球](打网球.md)**：馆和约球软件最密。
- **[打匹克球](打匹克球.md)** 和网球共用半片场的故事很多，圈子却是新的。
- **[打气排球](打气排球.md)** 不是软式排球课间游戏，是有联赛的矮网球。
- **[打毽球](打毽球.md)** 有网、有队；公园踢毽见 [踢毽子](../其他运动/踢毽子.md)。
- **[打台球](打台球.md)** 中式八球和斯诺克分桌；**[打壁球](打壁球.md)** 是四面墙。
- **[打门球](打门球.md)** 活动站和老年体协多；**[打高尔夫](打高尔夫.md)** 练习场和下场是两档花费。
- **[打保龄球](打保龄球.md)** 馆即可，联谊比联赛多。
