# 跳水

`运动与户外/水上/跳水` · Diving

词表种子：跳台跳板技术练习。业余入口窄；和 [游泳](游泳.md) 共用泳池，但不是「跳下去玩」。

## 这是什么（人话）

从跳板（1 米 / 3 米）或跳台（5 / 7.5 / 10 米）起跳，空中做动作，入水。业余能练的馆少，多数城市只有体校池开很窄的窗口。从桥上、悬崖往下跳不是这片叶子。

## 怎么玩 / 圈子里聊什么

- 板：弹板节奏；台：走台和起跳。高度按教练进度加，不自己爬。
- 向前 / 向后 / 向内 / 反身，周数和水花。圈子聊动作编号，不聊谁敢跳更高。
- 保护：教练、保护垫、池水深度。没有班就先别碰台。
- 和 [游泳](游泳.md) 的圈距训练不是一回事，泳班不会教这个。

跳水馆业余班、体校兴趣班、协会培训是仅有的正经入口。没有教练、没有开放跳台的馆，这片叶子对你暂时关着。不要无保护加难度、加高度，也不要去野外跳水。

## 入门线索

- 线上：跳水馆业余班招生、协会课讯。能搜到的城市不多。
- 线下：有跳板/跳台且开业余时段的馆、体校周末兴趣班。
- 起点：先问本地有没有业余班。没有就别爬台。会游泳是底，见 [游泳](游泳.md)。
