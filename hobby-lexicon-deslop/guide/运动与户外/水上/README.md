# 水上

运动与户外下的水亚类。9 片叶子：游、潜、浪、桨、帆、艇、跳。都要先解决「会不会沉」。

## 边界

- **[游泳](游泳.md)** 是底座：泳馆圈距、公开水域。铁三、自由潜、水肺都从这里要泳力。
- **[休闲潜水](休闲潜水.md)** 背气瓶看水下，考证（OW 一类）是圈子门槛；**[自由潜水](自由潜水.md)** 屏息，AIDA/SSI 另一套课，别混报名。
- **[冲浪](冲浪.md)** 等浪、板和浪向；**[桨板](桨板.md)** 是 SUP，平水也能玩。
- **[皮划艇](皮划艇.md)** 人坐/跪在艇里划；**[赛艇](赛艇.md)** 是滑座长桨，艇库和测功仪。
- **[帆船运动](帆船运动.md)** 俱乐部出航、抢口，不是邮轮观光。
- **[跳水](跳水.md)** 跳板跳台，业余入口窄，和「跳水玩」不是一回事。

下水相关：结伴、看天气和水流、按当地规定穿救生衣。叶子写爱好圈怎么练，不写无向导硬闯未知水域。
