# 冰雪

四季里最短的一季。4 片叶子：滑、雪、冰球、冰壶。南方城市多半靠室内冰场，雪要出差。

## 边界

- **[滑冰](滑冰.md)** 冰场滑行，花样是分支，不是必须。
- **[滑雪](滑雪.md)** 双板和单板都算，雪场课和约伴群季节性极强。
- **[打冰球](打冰球.md)** 冰上对抗，装备和场次都贵，和滑冰不是「会滑就会打」。
- **[打冰壶](打冰壶.md)** 投壶扫冰，体验馆就能碰，联赛另说。

旱地冰球、轮滑球不在这四片里。轮子见 [玩轮滑](../骑行轮滑/玩轮滑.md)。

## 叶子

1. [打冰壶](打冰壶.md)
2. [打冰球](打冰球.md)
3. [滑冰](滑冰.md)
4. [滑雪](滑雪.md)

线上常见落点：滑雪吧、雪场约伴群、冰场会员群。线下是室内冰场、北方雪场、冰壶体验馆——季前把装备和课约上，比到了坡上再问「有没有单板」省事。
