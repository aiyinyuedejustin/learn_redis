# 巴西柔术

`运动与户外/武术格斗/巴西柔术` · Brazilian jiu-jitsu

词表种子：地面缠斗与降服。投技规则不同，见 [练柔道](练柔道.md)。

## 这是什么（人话）

把人拖到地上，用位置和关节技结束。道馆日课是打点（drilling）加对抗滚（rolling）：封闭护身、过腿、骑乘、断头台、十字固、三角绞。Gi 抓衣、No-Gi 抓肉，规则和出汗味道都不一样。柔道也有寝技，但柔道馆优先把人摔下去；BJJ 馆从第一天就在垫上找降服。

## 怎么玩 / 圈子里聊什么

- 白带蓝带最容易死磕体力和蛮力，老师会按着你放松。
- Gi 还是 No-Gi 为主，周末公开垫（open mat）去哪家。
- IBJJF 积分赛、当地锦标赛，有人打、更多人只滚不赛。
- 术语：guard、mount、sweep、tap。先学会拍垫认输，再谈绞技。

BJJ 道馆是主场，综合格斗馆常有柔术课时。和 [练柔道](练柔道.md) 有时共用垫，课表、腰带、规则别混。白带前三个月腰酸、耳朵疼是正常课金，不是被针对。

## 入门线索

- 线上：BJJ 吧、各城道馆学员群、公开垫约滚。
- 线下：巴西柔术道馆试课、MMA 馆的柔术课时。
- 起点：租或借 Gi，先上基础站位和拍垫。别先买昂贵比赛道袍。
