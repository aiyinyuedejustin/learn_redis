# 武术格斗

运动与户外下的武馆亚类。13 片叶子：拳架、器械、站立打击、地面、剑道场。都按爱好写，不按职业选手写。

## 边界

传统拳和对抗项目别揉成一个「练武术」：

- **[中国武术](中国武术.md)** 是最宽的筐：套路、功法、还没选定门派。
- **[练太极拳](练太极拳.md)** 拳架和推手；**[太极剑](太极剑.md)** 是剑器，别跟拳架混成一页作业。
- **[八卦掌](八卦掌.md)** 走圈，**[形意拳](形意拳.md)** 五行直线，**[咏春拳](咏春拳.md)** 木人桩和黏手——三体内家常被一块聊，练法不是一套。
- **[练拳击](练拳击.md)** 只用手；**[搏击](搏击.md)** 在词表里是踢拳/泰拳馆，拳腿膝肘。
- **[巴西柔术](巴西柔术.md)** 地面降服；**[练柔道](练柔道.md)** 投技加寝技，摔的规则不同。
- **[练空手道](练空手道.md)** 型与组手，**[练跆拳道](练跆拳道.md)** 品势与踢击对打。
- **[练击剑](练击剑.md)** 是花剑重剑佩剑，不是影视开刃，也不是太极剑。
