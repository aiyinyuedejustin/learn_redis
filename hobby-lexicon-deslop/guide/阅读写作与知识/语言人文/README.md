# 语言人文

阅读写作与知识下最宽的亚类。7 片叶子：三种外语路径，四条史哲谱系。

## 边界（避免看成百科词条）

语言三片，别混成一个「学外语」：

- **[语言学习](语言学习.md)**：总筐。语伴、输入输出、多语自学。还没钉死语种的人先落这里。
- **[日语学习](日语学习.md)**：五十音、JLPT、看番当输入的那条线。
- **[英语学习](英语学习.md)**：听说读写爱好向精进。应试班、出国中介不在范围内。

人文四片，别混成一个「国学」：

- **[历史研读](历史研读.md)**：读书和史料，自己做笔记。
- **[口述历史](口述历史.md)**：开口问人、录音、整理。材料常补给历史和家谱。
- **[哲学阅读](哲学阅读.md)**：原著和讨论小组，不是心灵鸡汤。
- **[家谱研究](家谱研究.md)**：族谱、寻根、世系。和口述史重叠在「问家里人」，目标却是谱。

和 [读书会](../阅读/读书会.md) 的差别：读书会管组织共读；这里管题目本身（史、哲、谱、语言）。
