# 阅读

阅读写作与知识下的读者亚类。3 片叶子，都是「把书读完并找人说话」，不是识字教育。

## 边界

- **[读书会](读书会.md)** 是组织方式：约书、定进度、到点讨论。书目可以是任何类型。
- **[推理小说阅读](推理小说阅读.md)** 是类型读者圈：本格、社会派、剧透纪律。
- **[科幻阅读](科幻阅读.md)** 是另一类型圈：软硬科幻、杂志、奖项、读者会。

写推理/科幻去 [小说写作](../写作/小说写作.md)。哲学原著共读更靠近 [哲学阅读](../语言人文/哲学阅读.md)，虽然形式也像读书会。

## 叶子

1. [推理小说阅读](推理小说阅读.md)
2. [科幻阅读](科幻阅读.md)
3. [读书会](读书会.md)

线上常见落点：豆瓣推理/科幻小组和共读群、本格相关贴吧、《科幻世界》读者区。线下是书店主题场、图书馆读书会、科幻展和读者见面会。
