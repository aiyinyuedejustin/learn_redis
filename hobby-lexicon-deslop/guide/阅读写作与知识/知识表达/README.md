# 知识表达

阅读写作与知识下的「说给人听 / 写进公共知识」亚类。2 片叶子。

## 边界

- **[做播客](做播客.md)**：音频节目。策划、录、剪、shownote、上传。文字版可以挂到 [写博客](../写作/写博客.md)，但圈子聊的是声底和剪辑，不是排版。
- **[百科编辑](百科编辑.md)**：给维基百科等条目补来源、改错、开新条。志愿贡献，不是自媒体发通稿。

两片都要求有成品出门：一集节目，或一次过得去的编辑。只听播客、只读百科，不算这片叶子。

## 叶子

1. [做播客](做播客.md)
2. [百科编辑](百科编辑.md)

线上常见落点：小宇宙创作者区和听友群、中文维基互助客栈和编辑松报名页。线下是录音棚开放日、图书馆/博物馆编辑松、播客见面会。
