# 阅读写作与知识

词表大类。16 片叶子：写、读、学语言、把知识说给人听。

这里不写「文学史」「语言学概论」。写的是人怎么把一篇博客发出去、怎么约一场本格推理局、家谱群在吵什么攀附始祖。重叠很正常——写小说的人也在读书会晃，做播客的人常常同时写博客。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看四个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [语言人文](语言人文/README.md) — 外语、史哲、口述、家谱
- [写作](写作/README.md) — 博客、小说、诗、手账
- [阅读](阅读/README.md) — 共读、推理、科幻
- [知识表达](知识表达/README.md) — 播客、百科编辑
