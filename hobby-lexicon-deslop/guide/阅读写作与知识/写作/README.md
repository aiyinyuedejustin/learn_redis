# 写作

阅读写作与知识下的动手亚类。4 片叶子，都是「自己落笔」，不是「研究作家」。

## 边界（避免看成百科词条）

- **[写博客](写博客.md)** 是面向公开读者的长文和个人站点。和公众号、短视频不是同一圈；和 **[做播客](../知识表达/做播客.md)** 常是同一拨人换介质。
- **[小说写作](小说写作.md)** 管虚构：大纲、连载、网文站点、创意写作课。读别人的小说在 [推理小说阅读](../阅读/推理小说阅读.md) / [科幻阅读](../阅读/科幻阅读.md)。
- **[日记手账](日记手账.md)** 是写给自己看的：日记、手账、子弹笔记。晒本子可以，但主场不是发表。
- **[诗歌写作](诗歌写作.md)** 专管写诗和投稿朗诵。古体和现代诗在同一片叶子，圈子却常分开坐。

## 叶子

1. [写博客](写博客.md)
2. [小说写作](小说写作.md)
3. [日记手账](日记手账.md)
4. [诗歌写作](诗歌写作.md)

线上常见落点：独立博客聚合（十年之约、BlogFinder、开往）、网文作者区、手账/文具小组、诗社和投稿信箱。线下是写作工坊、朗读夜、文具市集——群名会变，场所类型比较稳。
