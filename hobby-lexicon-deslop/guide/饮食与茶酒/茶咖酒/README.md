# 茶咖酒

饮食与茶酒下的杯盏亚类。12 片叶子：冲、泡、品、藏、酿、调。都按爱好写，不按岗位写。

## 边界

茶四片，别混成一个「茶文化」：

- **[品茶](品茶.md)**：六大茶类对比喝，审评口径。
- **[茶艺](茶艺.md)**：茶席、手法、奉茶，动手和仪式感更重。
- **[岩茶品鉴](岩茶品鉴.md)**：武夷山场和焙火。
- **[普洱茶收藏](普洱茶收藏.md)**：饼、仓、年份，喝和藏绑在一起。

咖啡两片：

- **[咖啡冲煮](咖啡冲煮.md)**：手冲和意式，豆子已经烘好。
- **[家庭烘焙咖啡](家庭烘焙咖啡.md)**：生豆进炉，记曲线再杯测。

酒五片，词表里的 **[品酒](品酒.md)** 专指**葡萄酒**。威士忌、白酒、黄酒、自酿啤酒各自成叶。**[调酒](调酒.md)** 是鸡尾酒，不是品蒸馏酒。
