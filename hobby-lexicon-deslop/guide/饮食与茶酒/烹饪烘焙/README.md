# 烹饪烘焙

饮食与茶酒下的灶台亚类。8 片叶子，都是「自己下手」，不是「研究菜系」。

## 边界（避免看成百科词条）

- **[烹饪](烹饪.md)** 是最大的筐：家庭菜、菜单、火候、今天吃什么。川菜、烧烤、面食都从这里分岔出去。
- **[川菜烹饪](川菜烹饪.md)** 专指川味复刻：豆瓣、花椒、炼红油、馆子菜回家做。
- **[烧烤](烧烤.md)** 是炭火/烤串场景，不是「烤肉店测评」。
- **[烘焙](烘焙.md)** 管烤箱里的蛋糕饼干甜点；**[面包制作](面包制作.md)** 管面团和发酵；**[甜品制作](甜品制作.md)** 管裱花和点心造型。三块互相串门，圈子却不全是同一群人。
- **[面食制作](面食制作.md)** 是中式水饺包子面条；和欧包 overlap 只在「和面」。
- **[发酵食品](发酵食品.md)** 养菌、养坛、养 SCOBY，和面包种、家酿啤酒隔壁。
