# 饮食与茶酒

词表大类。20 片叶子：一半在灶台和烤箱，一半在杯盏里。

这里不写「川菜史」「茶的分类学」。写的是人怎么复刻一盘回锅肉、怎么约一场岩茶局、家酿啤酒群在吵什么。重叠很正常——做欧包的人也在发酵食品圈晃，岩茶局和茶艺课常是同一拨人。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看两个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [茶咖酒](茶咖酒/README.md) — 茶、咖啡、酿造与品饮（爱好向，合法自饮）

## 阅读提示

酒精和发酵都按**爱好、自用、合法**写。蒸馏白酒、对外售卖自酿、无证经营不在范围内。图片全部热链 Wikimedia Commons，图注里有文件页。
