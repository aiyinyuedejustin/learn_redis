# 水族两爬

动植物与自然下的缸、池、箱亚类。7 片叶子：淡水观赏鱼、草缸构图、海缸、锦鲤池、金鱼、龟、爬宠。都是「自己养」，不是水族馆导览。

## 边界（避免看成百科词条）

- **[水族饲养](水族饲养.md)** 是最大的筐：开缸、循环、水质、鱼种搭配。草缸审美划去 **[水族造景](水族造景.md)**，盐水和珊瑚划去 **[海水鱼缸](海水鱼缸.md)**。
- **[水族造景](水族造景.md)** 盯构图、石组、水草修剪和比赛照，不只是「缸里有草」。
- **[养锦鲤](养锦鲤.md)** 是池养品鉴，和缸养金鱼不是同一圈。**[金鱼饲养](金鱼饲养.md)** 谈兰寿、狮头、草金。
- **[养龟](养龟.md)** 晒背和水位；蜥蜴、守宫、蛇在 **[爬宠饲养](爬宠饲养.md)**。龟有时和鱼混养，圈子仍分开。
