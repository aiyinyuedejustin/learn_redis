# 动植物与自然

词表大类。29 片叶子：看、养、种、钓。人不只是在认物种，是在出门记鸟、开缸养水、阳台种月季、河边甩路亚。

这里不写「猫科分类」「兰科系统学」。写的是鸟友怎么报 life list、草缸群在吵灯和二氧化碳、兰友怎么度夏、台钓和路亚为什么不是一拨人。重叠很正常——观蝶的人常常也拍甲虫，养鱼的人会窜到造景比赛，阳台种菜和水培是同一块窗台。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看五个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。
