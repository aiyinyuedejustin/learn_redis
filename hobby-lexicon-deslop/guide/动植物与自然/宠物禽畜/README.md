# 宠物禽畜

动植物与自然下的「养在身边」亚类。5 片叶子：兔、狗、猫、蜂、笼鸟。叶子是饲养和圈子，不是物种介绍。

## 边界

- **[养猫](养猫.md)** / **[养狗](养狗.md)** 是最大的两拨：行为、医疗、出门和社群。训犬是养狗圈里的日常话题，不是单独叶子。
- **[养兔](养兔.md)** 垂耳兔和兔舍，和「农场养兔」不是同一套闲聊。
- **[养鸟](养鸟.md)** 是笼鸟、文鸟、鹦鹉；野外认鸟去 [观鸟](../自然观察/观鸟.md)。
- **[养蜂](养蜂.md)** 业余蜂箱和摇蜜。拍蜜蜂、认传粉昆虫更靠近 [昆虫观察](../自然观察/昆虫观察.md)。

合法饲养、检疫、禁养名录按当地规定。野生动物当宠物、无证贩卖不在范围内。
