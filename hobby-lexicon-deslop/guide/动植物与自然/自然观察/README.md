# 自然观察

动植物与自然下的「出门看」亚类。8 片叶子：鸟、蝶、虫、鲸、星、云、石头、蘑菇。对象在野外，人不把它们带回家当宠物——那是隔壁水族和宠物叶的事。

## 边界

- **[观鸟](观鸟.md)** 认鸟、记名录、报新种。望远镜和单筒是标配。
- **[观蝶](观蝶.md)** 专盯蝴蝶：翅纹、寄主植物、季节。甲虫、蜻蜓划去 **[昆虫观察](昆虫观察.md)**。
- **[昆虫观察](昆虫观察.md)** 更宽：拍、认、偶尔做标本，不等于「抓来养」。
- **[观鲸](观鲸.md)** 是沿海行程和船班，不是水族馆玻璃缸。
- **[业余天文](业余天文.md)** 晚上看天；白天看云是 **[气象观察](气象观察.md)**。
- **[业余地质](业余地质.md)** 捡石头、对矿物，不是矿洞探险教程。
- **[野外采菇](野外采菇.md)** 先认后采，叶子反复强调：**对照不等于能吃**。
