# 植物园艺

动植物与自然下的种植亚类。6 片叶子，都是「自己下手」，不是植物园导览，也不是中药材清单。

## 边界

- **[家庭园艺](家庭园艺.md)** 是最大的筐：阳台、院子、菜和花，跟着季节走。室内观叶划去 **[养观叶植物](养观叶植物.md)**。
- **[养多肉](养多肉.md)** 景天科那一摊：度夏、缀化、叶插换盆。和观叶 重叠 只在「也是盆栽」。
- **[兰花栽培](兰花栽培.md)** 国兰、洋兰分开聊；**[月季栽培](月季栽培.md)** 是蔷薇科开花管理，不是「花园里有玫瑰」。
- **[水培种植](水培种植.md)** 无土和营养液，和土培园艺隔壁，有人两种都玩。
