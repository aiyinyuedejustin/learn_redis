# 钓猎自然

动植物与自然下的钓法亚类。词表这一支目前 3 片叶子，**全是钓鱼**：台钓海钓、路亚、飞蝇。没有打猎、没有捕兽夹。名字里的「猎」别理解成持枪。

## 边界

- **[钓鱼](钓鱼.md)** 是最大的筐：台钓、传统钓、海钓、窝料和钓点。路亚手法划去 **[路亚钓鱼](路亚钓鱼.md)**，飞蝇线划去 **[飞蝇钓](飞蝇钓.md)**。
- **[路亚钓鱼](路亚钓鱼.md)** 假饵、搜索、黑鲈/翘嘴，和台钓的饵料哲学相反。
- **[飞蝇钓](飞蝇钓.md)** 飞蝇竿、毛钩、溪流抛投，人更少、装备话术更密。

禁钓期、水域许可、放流和外来物种规定按当地来。叶子不写怎么偷钓、电鱼、毒鱼。

## 叶子

1. [路亚钓鱼](路亚钓鱼.md)
2. [钓鱼](钓鱼.md)
3. [飞蝇钓](飞蝇钓.md)

线上常见落点：钓鱼吧、路亚吧、飞蝇钓吧、钓点约伴群。线下是水库和河道合规钓位、路亚钓场、溪流飞蝇点、渔具店周末局——卖竿的店可以当入口，叶子本身仍是业余垂钓。
