# 编织缝绣

手作与工艺下的针线亚类。10 片叶子：绣、缝、织、染、皮。都按自己下手写，不按「纺织工业」。

## 边界（避免看成百科词条）

- **[做刺绣](做刺绣.md)** 是广义手绣：苏绣、绣绷、针法。**[绣十字绣](绣十字绣.md)** 只指数格绣，绣格和图案交换是另一群人。
- **[家庭缝纫](家庭缝纫.md)** 管裁衣服、改裤脚、布艺；**[拼布手作](拼布手作.md)** 管拼布和绗缝被子。缝纫机两边都会用，圈子不完全重合。
- **[手工编织](手工编织.md)** 在词表里专指**棒针**；**[钩针编织](钩针编织.md)** 是钩针。毛线店常同时卖两套工具，群却常是分开的。
- 染色三片别混成「扎个蓝的」：**[玩扎染](玩扎染.md)** 是绑扎/絞り；**[玩蓝染](玩蓝染.md)** 是靛蓝缸；**[玩蜡染](玩蜡染.md)** 是蜡防染。蓝染工坊里也能碰到扎结，叶子本身仍按工艺分开。
- **[皮具制作](皮具制作.md)** 是皮革手缝，不归缝纫机改衣。
