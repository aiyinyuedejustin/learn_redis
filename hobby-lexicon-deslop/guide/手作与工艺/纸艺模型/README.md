# 纸艺模型

手作与工艺下的纸与模型亚类。7 片叶子：剪、折、拓、积木、比例模型。都按自己上手写，不按「玩具工业」或「金石学」。

## 边界

纸三片，别混成一个「纸艺」：

- **[做剪纸](做剪纸.md)**：窗花、阴刻阳刻，剪刀或刻刀。
- **[折纸](折纸.md)**：不剪少胶，折痕和几何。
- **[拓片](拓片.md)**：碑上纸、墨，和剪折不是一回事；和篆刻叶在「金石」上碰面。

模型四片：

- **[乐高拼搭](乐高拼搭.md)**：积木和 MOC，不是比例模型涂装。
- **[模型制作](模型制作.md)**：词表里的大筐，军事模型、载具、船，拼装涂装。高达、铁道从这里分岔。
- **[高达模型](高达模型.md)**：敢达/Gunpla，素组、涂装、改件。
- **[铁道模型](铁道模型.md)**：沙盘和跑车，N 比例常被点名。
