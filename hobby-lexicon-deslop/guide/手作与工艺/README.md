# 手作与工艺

词表大类。32 片叶子：针线、纸模、硬材料、花香、轻手作、家里动手。

这里不写「刺绣史」「乐高公司年表」。写的是人怎么绣一朵花、怎么素组一台高达、陶艺工作室会员群在吵什么。重叠很正常——钩针的人也在棒针圈晃，金工课和首饰叶常是同一拨人。遇到跨界，叶子页会互相指一下。
