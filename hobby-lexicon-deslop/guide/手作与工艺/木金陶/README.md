# 木金陶

手作与工艺下的硬材料亚类。6 片叶子：木、金、陶、玻璃、印石。都按爱好写，不按木匠铺或工厂岗位写。

## 边界

- **[业余木工](业余木工.md)** 做家具和小件：锯、刨、榫卯。**[做木雕](做木雕.md)** 是刻刀出形，不是做柜子。创客空间两边都会碰到，圈子话术不同。
- **[业余金工](业余金工.md)** 是金属加工和首饰胚：锯、焊、锤。串珠和金属丝入门去 **[首饰制作](../轻手作/首饰制作.md)**。
- **[玩陶艺](玩陶艺.md)** 拉坯釉烧，工作室会员制最常见。
- **[吹玻璃](吹玻璃.md)** 几乎必须进工坊，家里没有炉。体验课和会员是两条门槛。
- **[练篆刻](练篆刻.md)** 是印石和刀法，和拓片叶在金石圈重叠。
