# 花艺香道

手作与工艺下的花与香亚类。4 片叶子：插、养、压、制。都按自己动手写，不按花店岗位或香道仪轨考证写。

## 边界

- **[学花艺](学花艺.md)** 是插花和花束：剑山、包装、西式花艺课。鲜切花，做完就谢。
- **[养盆景](养盆景.md)** 是活树：蟠扎、修根、过冬。和花艺课不是一拨人，花友圈里会串门。
- **[做押花](做押花.md)** 把花压干再做成卡片或画，和插花的时间尺度相反。
- **[制香](制香.md)** 合香、线香，只写**合规原料、自用交流**。管制成分、对外无证售卖不在范围内。

## 叶子

1. [做押花](做押花.md)
2. [养盆景](养盆景.md)
3. [制香](制香.md)
4. [学花艺](学花艺.md)

线上常见落点：插花协会/花艺培训、盆景协会、押花吧、制香吧/香友会。线下是花艺教室、盆景园、香席小局——花店和香铺可以当入口，叶子本身仍是业余实践。
