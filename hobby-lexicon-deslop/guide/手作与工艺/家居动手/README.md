# 家居动手

手作与工艺下最生活的亚类。1 片叶子，专管家里的改造和维修，不按装修公司岗位写。

## 边界

- **[DIY家居](DIY家居.md)** 是刷墙、打孔、换五金、改旧家具、自己装搁板。木工榫卯去 **[业余木工](../木金陶/业余木工.md)**；这里更杂、更就地取材。
- 叶子是「自己动手」，不是「盯工地」或「评 inspirational 装修图」。电路、燃气、承重墙按合规和请持证师傅写。

## 叶子

1. [DIY家居](DIY家居.md)

线上常见落点：DIY家居吧、改造分享圈、各城市二手工具群。线下是建材市场、工具租赁、创客空间的家用工具区——场所类型比具体群名稳。
