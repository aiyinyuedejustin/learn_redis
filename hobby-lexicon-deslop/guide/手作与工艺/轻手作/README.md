# 轻手作

手作与工艺下的桌面小件亚类。4 片叶子：皂、蜡、土、饰。门槛低、材料轻，厨房和书桌就能开始；安全账仍要算。

## 边界

- **[手工皂](手工皂.md)** 分皂基熔浇和冷制皂化。冷制要碰氢氧化钠，圈子里真在练的是配方计算和防护，不是「天然」两个字。
- **[香薰蜡烛](香薰蜡烛.md)** 浇蜡、调香、选灯芯。和制香叶都谈气味，一个是蜡，一个是焚香。
- **[粘土手作](粘土手作.md)** 超轻土、树脂粘土，捏小件和配件。陶艺拉坯去 **[玩陶艺](../木金陶/玩陶艺.md)**。
- **[首饰制作](首饰制作.md)** 串珠、金属丝、简单金工。焊台和锯床级的金属加工去 **[业余金工](../木金陶/业余金工.md)**。
