# 音乐与演奏

词表大类。37 片叶子：手上的、嘴里的、耳朵上的。

这里不写「钢琴史」「民族乐器分类学」。写的是人怎么回课、怎么约排练房、乐理群在吵什么。重叠很正常——弹吉他的人也在乐队排练晃，编曲和音乐制作常是同一拨人。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看八个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [民族乐器](民族乐器/README.md) — 笛箫笙管、琴筝琵琶阮、二胡唢呐
- [声乐](声乐/README.md) — 唱、合唱、说唱、K 歌、业余乐队
- [管乐](管乐/README.md) — 西洋木管铜管，外加口琴陶笛
- [创作制作](创作制作/README.md) — 乐理、作曲、编曲、制作、打碟
- [弦乐](弦乐/README.md) — 吉他、尤克里里、小提琴、大提琴
- [打击乐](打击乐/README.md) — 爵士鼓、非洲鼓、鼓圈
- [键盘](键盘/README.md) — 钢琴、电子琴/合成器、手风琴
- [鉴赏](鉴赏/README.md) — 黑胶、CD、HIFI 听碟（不演奏）
