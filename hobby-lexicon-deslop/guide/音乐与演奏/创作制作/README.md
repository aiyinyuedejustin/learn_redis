# 创作制作

音乐与演奏下的写和做亚类。5 片叶子：听得懂、写得出来、编得满、录得干净、现场接得上。

## 边界

四片制作向，别混成一个「做音乐」：

- **[乐理学习](乐理学习.md)**：视唱练耳、音程和弦，给后面垫底。
- **[作曲](作曲.md)**：旋律、和声、乐句，盯曲子本身。
- **[编曲](编曲.md)**：配器、MIDI、宿主里把骨架填满。
- **[音乐制作](音乐制作.md)**：录音、混音、导出。卧室制作人是主力。

**[打碟DJ](打碟DJ.md)** 是现场控场和混音衔接，不是写歌。收碟听碟见 [唱片收藏聆听](../鉴赏/唱片收藏聆听.md)，两边都碰黑胶，干的事不同。

词曲写完要唱，会串到 [流行演唱](../声乐/流行演唱.md)、[说唱](../声乐/说唱.md)。会弹琴的人常从 [弹钢琴](../键盘/弹钢琴.md) 拐进来学乐理。
