# 弦乐

音乐与演奏下的西洋拨弦/弓弦亚类。4 片叶子。民乐里的琴筝琵琶阮、二胡不在这里，见 [民族乐器](../民族乐器/README.md)。

## 边界

- **[弹吉他](弹吉他.md)**：民谣弹唱是国内最大入口；电吉他走乐队和效果器。
- **[弹尤克里里](弹尤克里里.md)**：四弦、好带，和吉他 overlap 只在「和弦弹唱」。
- **[拉小提琴](拉小提琴.md)**：音阶、换把、业余乐团常见入口。
- **[拉大提琴](拉大提琴.md)**：运弓、把位，室内乐和业余乐团大提琴声部常缺人。

吉他手去组队，见 [乐队排练](../声乐/乐队排练.md)。弓弦的识谱会用到 [乐理学习](../创作制作/乐理学习.md)。
