# 管乐

音乐与演奏下的西洋管乐亚类。6 片叶子。竹笛洞箫唢呐不在这里，见 [民族乐器](../民族乐器/README.md)。

## 边界

- **[吹长笛](吹长笛.md)** 专指西洋横笛，金属管、无膜。竹笛是另一页。
- **[吹单簧管](吹单簧管.md)** 和 **[吹萨克斯](吹萨克斯.md)** 都用哨片，嘴劲能串，曲子和圈不完全重合。
- **[吹小号](吹小号.md)** 是铜管，嘴唇当簧片。
- **[吹口琴](吹口琴.md)**：十孔布鲁斯和半音阶口琴，词表收在一片，圈子却常是两拨人。
- **[吹陶笛](吹陶笛.md)**：陶土开孔，游戏音乐和自学视频带进来的人最多；和葫芦丝一样好上手。

合奏主场是学校/城市管乐团、铜管五重奏、爵士 Jam。居民楼练管，弱音器和时辰是高频话题。
