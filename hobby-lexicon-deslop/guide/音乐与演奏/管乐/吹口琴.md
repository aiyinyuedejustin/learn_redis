# 吹口琴

`音乐与演奏/管乐/吹口琴` · Playing harmonica

词表种子：布鲁斯与半音阶口琴。口袋乐器，和 [吹陶笛](吹陶笛.md) 一样好带；和萨克斯的布鲁斯场有时重叠。

## 这是什么（人话）

十孔布鲁斯口琴（blues harp）和半音阶口琴是两个圈子，词表收在一片。前者盯 bending、调性和手捂；后者有滑钮，古典和流行都能走。口袋里能装，局多。叶子写吹，不写收藏老琴目录。

## 怎么玩 / 圈子里聊什么

- 一把 C 调走不完，布鲁斯要换调。
- bending、overblow，嘴型和气。
- 半音阶：滑钮时机、漏气。
- 手捂哇音，录音和现场差一截。

口琴吧和协会是主场。布鲁斯 Jam、民谣弹唱局、地铁口都可能是练习场。和吉他弹唱很配，变调夹对口琴调性要算。

## 入门线索

- 线上：口琴吧、协会、布鲁斯 Jam 转发。
- 线下：协会活动、Jam、公园。
- 起点：十孔 C 调 + 基础音阶。想走布鲁斯再加一把 G 或 A；想走半音阶另买，别混成一把。
