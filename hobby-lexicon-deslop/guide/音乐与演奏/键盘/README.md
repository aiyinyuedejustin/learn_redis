# 键盘

音乐与演奏下的键盘亚类。3 片叶子。

## 边界

- **[弹钢琴](弹钢琴.md)**：立式、三角、电钢当钢琴练，独奏和伴奏。
- **[弹电子琴](弹电子琴.md)**：功能琴、便携键盘、合成器，词表收在一片。自动伴奏派和「当钢琴用」派常不对付。
- **[拉手风琴](拉手风琴.md)**：风箱和贝斯钮，协会和老年大学是线下主力。

钢琴是 [乐理学习](../创作制作/乐理学习.md) 最常见的教具。MIDI 键盘进宿主，见 [编曲](../创作制作/编曲.md)。给别人弹伴奏，会串到 [合唱](../声乐/合唱.md)、[美声唱法](../声乐/美声唱法.md)、[流行演唱](../声乐/流行演唱.md)。

## 叶子

1. [弹电子琴](弹电子琴.md)
2. [弹钢琴](弹钢琴.md)
3. [拉手风琴](拉手风琴.md)

线上常见落点：钢琴吧、琴行学员群、电子琴考级圈、手风琴协会。线下是回课、社区琴房、广场和室内乐小乐队。
