# 声乐

音乐与演奏下的嗓子和组队亚类。6 片叶子。词表把**业余乐队**也放在这里：主场是排练房，不是独唱教室。

## 边界

唱的四片，别混成一个「唱歌」：

- **[卡拉OK](卡拉OK.md)**：包房、点歌、麦序，社交优先。
- **[流行演唱](流行演唱.md)**：停下来改气口和换声，练的是唱法。
- **[美声唱法](美声唱法.md)**：艺术歌曲和发声，不是听歌剧故事。
- **[合唱](合唱.md)**：声部、指挥、公演，一个人再好听也要让路。

另外两片：

- **[说唱](说唱.md)**：词和 flow，录音棚和 battle 是两个场。
- **[乐队排练](乐队排练.md)**：约房、对拍、演出。吉他手、鼓手会从 [弦乐](../弦乐/README.md)、[打击乐](../打击乐/README.md) 串过来。

视唱练耳见 [乐理学习](../创作制作/乐理学习.md)。翻唱录音、做人声后期见 [音乐制作](../创作制作/音乐制作.md)。
