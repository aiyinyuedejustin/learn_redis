# 打击乐

音乐与演奏下的打节奏亚类。3 片叶子。

## 边界

- **[打鼓](打鼓.md)**：爵士鼓 / 鼓组，排练房和乐队是主场。
- **[打非洲鼓](打非洲鼓.md)**：手鼓手法、西非节奏型，课和工作坊更抠对错。
- **[鼓圈](鼓圈.md)**：一圈人即兴，社交和 Pulse 优先，不是个人秀。

非洲鼓和鼓圈人重叠很多，场合不同：一边在练 slap 是否脆，一边在公园里别把节奏带崩。鼓手组队见 [乐队排练](../声乐/乐队排练.md)。编电子鼓组见 [编曲](../创作制作/编曲.md)，那是宿主里的事。

## 叶子

1. [打非洲鼓](打非洲鼓.md)
2. [打鼓](打鼓.md)
3. [鼓圈](鼓圈.md)

线上常见落点：鼓手吧、非洲鼓吧、城市鼓圈活动帖。线下是鼓房、周末手鼓课、公园/营地鼓圈。
