# 民族乐器

音乐与演奏下的民乐亚类。9 片叶子，都是「自己上手」，不是「中国音乐史」。

## 边界

吹的四片，别混成一支「笛子」：

- **[吹笛子](吹笛子.md)**：竹笛，有膜。
- **[吹箫](吹箫.md)**：洞箫，无膜，气更长。
- **[吹葫芦丝](吹葫芦丝.md)**：葫芦加竹管，常和巴乌一起被点名。
- **[吹唢呐](吹唢呐.md)**：哨片、音量大，班社和婚礼戏台是另一套场。

弹的四片：

- **[弹古琴](弹古琴.md)**：减字谱、雅集，和考级密集的古筝不是同一圈气质。
- **[弹古筝](弹古筝.md)**：21 弦、按滑揉，培训班最多。
- **[弹琵琶](弹琵琶.md)**：弹挑轮指，文曲武曲。
- **[弹阮](弹阮.md)**：中阮大阮，民乐团中声部，学的人少、团里却缺。

拉的一片：**[拉二胡](拉二胡.md)**。和西洋弦乐的小提琴大提琴见 [弦乐](../弦乐/README.md)。

西洋长笛见 [吹长笛](../管乐/吹长笛.md)，不要点进竹笛页。
