# 身心练习

词表大类。9 片叶子，全在一个亚类：**身心功法**。垫上、站着、坐着、走着都有，共同处是把注意力收回身体，而不是冲配速或堆重量。

这里不写「瑜伽哲学史」「气功门派谱系」。写的是人怎么跟一套八段锦、怎么约普拉提器械课、站桩吧在吵架高还是架低。重叠很正常——瑜伽馆也开拉伸，气功站也教八段锦，MBSR 小组和冥想 App 用户常是同一拨人。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看亚类里的边界（尤其是冥想 / 正念 / 呼吸，以及气功 / 八段锦 / 站桩），再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [身心功法](身心功法/README.md) — 伸展、呼吸、静坐、导引、瑜伽与普拉提

## 阅读提示

功法按**爱好、自练**写，不是医疗处方，也不讨论门派神通。闭气、伤膝、腰椎问题先问自己能不能练，再问群里「这个动作对不对」。图片全部热链 Wikimedia Commons，图注里有文件页。
