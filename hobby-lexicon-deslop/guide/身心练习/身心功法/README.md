# 身心功法

身心练习下的唯一亚类。9 片叶子：拉、坐、呼吸、站、导引、垫上。都按爱好写，不按养生馆推销词写。

## 边界

坐垫上的三片，别混成一个「冥想」：

- **[冥想练习](冥想练习.md)**：专门坐下来练，数息、静坐、引导音频。
- **[正念练习](正念练习.md)**：洗碗、走路也算练；MBSR 八周课是公开入口。
- **[呼吸练习](呼吸练习.md)**：呼吸本身是课，不是瑜伽里顺带提一句「用鼻子吸」。

传统功法三片，常在同一座公园里：

- **[练八段锦](练八段锦.md)**：固定八式，国家推广的健身气功里最常见的一套。
- **[站桩](站桩.md)**：几乎不动，抱圆、沉肩，武术圈当基本功。
- **[练气功](练气功.md)**：更宽：易筋经、五禽戏、六字诀、各门导引。八段锦和站桩都可能被算进来，词表单列。

垫上两片，馆不同、话术也不同：

- **[练瑜伽](练瑜伽.md)**：体式序列 + 呼吸，流派从流瑜伽到艾扬格。
- **[练普拉提](练普拉提.md)**：控制学，核心和脊柱中立，器械床是另一套价钱。
- **[伸展放松](伸展放松.md)**：只拉柔韧和放松。瑜伽馆延伸课、普拉提课后拉伸，人都在，课名不是瑜伽。
