# 旅行与地方探索

词表大类。14 片叶子：一半在「到了地方怎么看」，一半在「用什么方式把路走完」。

这里不写旅游概论，也不做目的地百科。写的是人怎么把一座馆走完、怎么在古镇里慢下来、车友群在吵哪个营地能排污。重叠很正常——citywalk 的人也会钻进古建，背包客常顺手坐慢火车。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看两个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [地方探索](地方探索/README.md) — 进到一个地方里看、走、找、拍
- [旅行方式](旅行方式/README.md) — 载具、住宿和节奏：车、轨、包、沙发、汤

## 阅读提示

户外、自驾、沙发客都按**爱好、合法、自己负责安全**写。未开发区域探险、无证运营、把别人家里当免费旅馆，都不在范围内。图片全部热链 Wikimedia Commons，图注里有文件页。
