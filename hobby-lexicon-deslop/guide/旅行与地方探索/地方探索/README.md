# 地方探索

旅行与地方探索下的「到了地方怎么看」亚类。7 片叶子：馆、建、镇、藏、街、道、镜头。

## 边界

别把「出去走走」揉成一团：

- **[博物馆参观](博物馆参观.md)**：按展览、展签、讲解走完一座馆。
- **[古建筑探访](古建筑探访.md)**：看梁架、形制、园林和乡土建筑，常带文保口径。
- **[古镇漫游](古镇漫游.md)**：在古镇老街里慢游，气氛比构件名称更先。
- **[地理寻宝](地理寻宝.md)**：按坐标找盒子，是规则明确的户外游戏。
- **[城市漫步](城市漫步.md)**：当代街区无目的走。古镇线见上一片。
- **[徒步穿越](徒步穿越.md)**：长距步道，轨迹、补给、下撤。不是周末爬个小山。
- **[摄影旅行](摄影旅行.md)**：先定机位和光线，再倒推交通住宿。

和 [旅行方式](../旅行方式/README.md) 的交集：背包客也会 citywalk，摄旅团常包车。叶子按**到了以后干什么**切，不按交通工具切。
