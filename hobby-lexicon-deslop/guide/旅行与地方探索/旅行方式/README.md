# 旅行方式

旅行与地方探索下的「路怎么走完」亚类。7 片叶子：房车、沙发、汤、火车、背包、自驾、骑行。

## 边界

载具和住宿别混：

- **[自驾游](自驾游.md)**：人开车，晚上多半住店或营地；车主要是交通。
- **[房车旅行](房车旅行.md)**：住在车上，营地水电、排污、营位比景点清单先谈。
- **[骑行旅行](骑行旅行.md)**：自行车驮包走长线。川藏是圈子里的硬话题，不是唯一玩法。
- **[火车旅行](火车旅行.md)**：线路、车次、车厢本身就是体验。
- **[背包旅行](背包旅行.md)**：一包走长线，青旅、巴士、便宜铁路是骨架。
- **[沙发客](沙发客.md)**：申请住进当地人家里，或只约见面。不是青旅，更不是免费旅馆。
- **[温泉旅行](温泉旅行.md)**：目的地围着泉质、汤屋和泡法转。

和 [地方探索](../地方探索/README.md) 的交集：背包客会进馆、骑行的人会拍、火车迷会在站台附近 citywalk。叶子按**出行骨架**切。
