# 角色扮演

游戏与电子娱乐下的扮演亚类。2 片叶子：一个站起来走，一个围桌掷骰。都按爱好写，不按戏剧学院或桌游店岗位写。

## 边界

别把两片揉成「角色扮演游戏」一个筐：

- **[桌上角色扮演](桌上角色扮演.md)**（跑团 / TRPG）：人坐着，骰子和规则书做仲裁，KP / DM 主持。国内常见入口是 COC、DND，线上语音团和线下桌店都有。
- **[LARP](LARP.md)**：人站起来，用走位、说话、服装推进。国内常见入口是沉浸剧本杀馆和换装剧场；也有泡沫武器、奇幻战团那种户外场。和桌上团的交集是「会演」，分歧是「要不要骰子说了算」。

狼人杀、密室逃脱会从旁边蹭人，但词表没给它们单独叶子。遇到跨界，叶子页会指一下。

## 叶子

1. [LARP](LARP.md)
2. [桌上角色扮演](桌上角色扮演.md)

线上常见落点：跑团吧、COC / DND 吧、豆瓣 TRPG 小组、城市面团群、剧本杀拼团群。线下是桌游店开的面团、跑团馆、沉浸剧本杀 / 演绎剧场、偶尔的户外战团活动。先问清楚是坐着掷骰还是换装进场，别约错。
