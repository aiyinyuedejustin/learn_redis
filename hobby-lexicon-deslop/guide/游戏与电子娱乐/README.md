# 游戏与电子娱乐

词表大类。11 片叶子：9 片在屏幕和机厅，2 片要站起来或围桌演。

这里不写「电子游戏编年史」「什么是元宇宙」。写的是人怎么约一场街机、怎么开荒一款新服、怎么找齐四个调查员、怎么在训练模式里抠一帧。重叠很正常——打格斗的人也泡复古厅，音游和街机柜经常隔两米，跑团群里总有人周末去沉浸馆。遇到跨界，叶子页会互相指一下。
