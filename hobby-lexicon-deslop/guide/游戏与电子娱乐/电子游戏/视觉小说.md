# 视觉小说

`游戏与电子娱乐/电子游戏/视觉小说` · Visual novel

词表种子：文字 AVG、视觉小说游玩。叙事独立作见 [独立游戏](独立游戏.md)。这片叶子写**读故事和收结局**，不写成人向细节，也不把未成年角色当话题。

## 这是什么（人话）

以阅读为主的游戏：立绘、对话框、少量选项，路线通向不同结局。中文圈常把日式美少女向叫 galgame，但叶子本身是更宽的视觉小说——推理、科幻、群像、完全没恋爱的也算。玩法是**读完、收齐、再决定评不评**，不是百科条目「视觉小说史」。

文本量大。三十小时只是常见中位，有的作要上百小时才全收集。音乐和 CV 是圈里正经话题；画风只是进门理由之一。

## 怎么玩 / 圈子里聊什么

- 真结局、坏结局、CG / 音乐收集。攻略能用，剧透要标。
- 汉化进度、补丁版本、官方中文。买正版、跟官方和汉化组公告，不把网盘当入门教程。
- 会社口味、文本密度、选项有没有实质分歧。「选项多不等于好玩」。
- 全收集和只走一条线，是两种玩法，约推荐时先说清楚。

美少女游戏吧、视觉小说向论坛、VNDB 查库、B 站无剧透安利是常见落点。Steam、官方商店、支持成年向合规渠道的平台是买的地方。圈子里最容易翻脸的是未标剧透。

## 入门线索

- 线上：视觉小说 / gal 向论坛、VNDB、Steam 标签「Visual Novel」、无剧透安利帖。
- 线下：少。偶见于同人展、独立游戏展的试玩台。
- 起点：先选一作有官方中文、时长几十小时内的，走完一条线再谈全收集。注意作品分级，只玩自己年龄允许的。
