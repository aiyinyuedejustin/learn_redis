# 电子游戏

游戏与电子娱乐下的屏幕亚类。9 片叶子，都是「自己玩或自己看」，不是「做游戏的人怎么上班」。

## 边界（避免看成百科词条）

- **[VR游戏](VR游戏.md)** 是头显和身体：守卫区、晕动、一体机或串流。和坐着打的排位不是同一套。
- **[复古游戏](复古游戏.md)** 管红白机、街机板、中古柜和官方复刻；不是「所有老游戏回忆录」。
- **[手机游戏](手机游戏.md)** 是开荒和日常肝的攻略圈。王者、和平精英那种上分，和 **[电子竞技](电子竞技.md)** 会撞车，这片叶子不写职业赛程。
- **[格斗游戏](格斗游戏.md)** 是对战格斗：帧、取消、手台。EVO 可以看，叶子本身是自己练和约战。
- **[模拟经营游戏](模拟经营游戏.md)** 建、管、堵、美；和独立游戏的交叉只在「这作是不是小团队做的」。
- **[独立游戏](独立游戏.md)** 是发掘和通关评论，不是独立开发教程。
- **[电子竞技](电子竞技.md)** 在词表里是**业余观赛与排位**，不是转会和合同。
- **[视觉小说](视觉小说.md)** 是读选项和收结局；和独立游戏、二次元圈都串门。
- **[音游](音游.md)** 是打歌。机厅柜和 [复古游戏](复古游戏.md)、[格斗游戏](格斗游戏.md) 常在同一层楼。
