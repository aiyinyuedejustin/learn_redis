# 音游

`游戏与电子娱乐/电子游戏/音游` · Rhythm games

词表种子：节奏游戏、打歌练习。机厅柜常和 [复古游戏](复古游戏.md)、[格斗游戏](格斗游戏.md) 挤在同一层；手机音游也和 [手机游戏](手机游戏.md) 交叉。

## 这是什么（人话）

跟着谱面按、划、踩、敲。街机这边是舞萌（maimai）、中二（CHUNITHM）、SDVX、IIDX、太鼓；家里是 osu!、手机上的 Phigros / Arcaea。叶子是**打歌**，不是做谱教程。

定数、达成率、理论值、段位是共同语言。手元（手怎么放）比外设神话先被问。厅里有礼仪：擦柜、不挡屏幕、高难请避开高峰。

## 怎么玩 / 圈子里聊什么

- 这张能吃几分、是配置问题还是读谱问题。
- 筐体版本、国服 / 国际服、刷卡存成绩。
- 约打：谁在哪家厅、几点有空机、能不能拼。
- 家里用模拟器练手，和厅里手感对不上——圈里的日经。

音游吧、各作玩家群、机厅约打群是主场。B 站手元和定数表当教材。和复古圈的交叉是老 DDR、老太鼓柜；和手游圈的交叉是那几款能装进口袋的。

## 入门线索

- 线上：音游吧、maimai / 中二 / osu! 群、成绩查询和定数表。
- 线下：城市机厅音游角、高校附近的厅、偶尔的官方赛。先去看一小时再投币。
- 起点：选一个柜，打官方推荐的入门谱，把判定和站位固定下来。别第一天就点红谱。
