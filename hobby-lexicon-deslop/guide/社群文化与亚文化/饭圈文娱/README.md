# 饭圈文娱

社群文化与亚文化下的文娱粉亚类。只有 2 片叶子，但圈里最容易被写成同一件事：**追人和追作品**。

## 边界

- **[偶像应援](偶像应援.md)**：演唱会、应援色、应援物、周边。叶子按**理性应援**写——灯牌和场控，不是网暴、不是扒隐私。
- **[影迷](影迷.md)**：片单、导演、影展、复看。讨论作品，不是跟偶像行程。

和二次元的 **[动漫追番](../二次元同人/动漫追番.md)**、迷文化的 **[科幻迷](../迷文化/科幻迷.md)** 会抢人：有人周五追番、周六跑应援、周日影展连场。各页只写自己那条主轴。

## 叶子

1. [偶像应援](偶像应援.md)
2. [影迷](影迷.md)

线上常见落点：粉丝站、应援物交流、影迷吧和电影小组。线下是 livehouse / 体育馆场次、电影院午夜场、影展问答——卖票的场可以当入口，叶子本身仍是业余实践。
