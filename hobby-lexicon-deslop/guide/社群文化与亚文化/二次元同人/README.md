# 二次元同人

社群文化与亚文化下的漫展/同人亚类。11 片叶子：看的、画的、穿的、开的。都按爱好写，不按「二次元产业」写。

## 边界

三件穿的，别揉成「漫展衣服」：

- **[Cosplay](Cosplay.md)**：扮演一个角色，有人设、有场照。
- **[JK制服爱好](JK制服爱好.md)**：日系制服当时装穿，**成年同好**；不是学校、也不是角色扮演。
- **[洛丽塔时尚](洛丽塔时尚.md)**：洋装 coord 和茶会。和 JK 店常在同一栋动漫城，圈子口径不同。
- **[汉服同好](汉服同好.md)**：形制和同袍，跟古装剧粉、跟 Cos 汉元素不是同一桌。

创作三片：

- **[动漫追番](动漫追番.md)**：看和聊，周边可以买，不一定自己画。
- **[同人创作](同人创作.md)**：画、写、做同人志，即卖会是主场。
- **[同人音声](同人音声.md)**：听和做广播剧/音声；词曲调教见 **[Vocaloid](Vocaloid.md)**。

另外四片各管一件事：**[BJD娃娃](BJD娃娃.md)** 是妆造和娃衣；**[特摄爱好](特摄爱好.md)** 是骑士和奥特曼；**[痛车改装](痛车改装.md)** 是车身痛贴；**[Vocaloid](Vocaloid.md)** 是歌声合成和演出。
