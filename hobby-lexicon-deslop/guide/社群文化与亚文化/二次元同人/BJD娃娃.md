# BJD娃娃

`社群文化与亚文化/二次元同人/BJD娃娃` · Ball-jointed doll

词表种子：妆造与摄影。洋装穿搭见 [洛丽塔时尚](洛丽塔时尚.md)；娃衣和人衣是两套尺码。

## 这是什么（人话）

养一只球型关节娃娃：开脸、补妆、换眼、穿衣、摆姿势拍照。树脂娃要避晒、避摔；圈子里真正耗时间的是**妆面和娃衣**，不是「拥有一只 Volks」。国内常见 1/3、1/4，也有更小的。叶子写的是成年娃圈实践，不是给小孩的玩具店货架。

## 怎么玩 / 圈子里聊什么

- 开脸还是买官方妆；密封剂、眉粉、水彩会不会糊。
- 眼珠直径、假发发旋、体型（SD / MSD / 叔体）对不上衣。
- 约拍：棚灯、外景、道具，以及「别用闪光灯直打树脂」。
- 二手头、分体、拆卖——新手最容易在这里花冤枉钱。

BJD 吧和娃圈约拍群是主场。线下是娃娃展、品牌见面会、城市约拍局；漫展偶有娃桌，但和 Cos 区不是一拨人。有人只拍照不改妆，有人只改妆不发图——都能算。

## 入门线索

- 线上：BJD 吧、娃圈拍照约拍群、妆面教程帖。
- 线下：娃娃展、品牌店体验、同城约拍（先看别人怎么摆关节）。
- 起点：一只二手头或小体 + 一套换眼练习。先学会卸妆和密封，再谈限量体。
