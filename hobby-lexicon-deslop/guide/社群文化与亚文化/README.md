# 社群文化与亚文化

词表大类。19 片叶子：穿的、画的、追的、拍的、应援的。都按**人在圈子里干什么**写，不按「亚文化史」写。

重叠很正常——漫展门口同时站着 Coser、痛车和追番的人；汉服店和洛丽塔店经常隔一条走廊；铁路迷和公交迷都在「拍车」，器材和术语却不是一套。遇到跨界，叶子页会互相指一下。

这片大类里的穿搭叶（JK、洛丽塔、汉服、Cosplay）按**成年同好**写。不写未成年人，也不写性化内容。

## 怎么逛

先看三个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [二次元同人](二次元同人/README.md) — 漫展、同人、娃、洋装、特摄、痛车
