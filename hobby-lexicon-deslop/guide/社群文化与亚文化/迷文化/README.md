# 迷文化

社群文化与亚文化下的「迷」亚类。6 片叶子：拍车、拍机、走路、读书、看装备。都是业余追踪，不是岗位。

## 边界

三片都在拍移动的铁，别混：

- **[公交迷](公交迷.md)**：线路、车型、场站，站台和总站。
- **[铁路迷](铁路迷.md)**：机车、车次、拍车点，高铁和普速都有人守。
- **[航空迷](航空迷.md)**：拍机、航线、机号，围栏外和航展。

另外三片各走一条：

- **[军迷](军迷.md)**：军史、公开资料、比例模型。守法交流，不写实弹和违规仿制。
- **[城市探险](城市探险.md)**：废墟和老建筑。安全和法规写在前面，不写怎么闯入。
- **[科幻迷](科幻迷.md)**：书刊、年会、奖项。看电影可以，但叶子主轴是圈，不是票房。

和饭圈文娱的 **[影迷](../饭圈文娱/影迷.md)** 比：科幻迷会为一部小说吵三年；影迷更常按导演和片单走。和二次元的 **[动漫追番](../二次元同人/动漫追番.md)** 也只在「追连载」上碰面。
