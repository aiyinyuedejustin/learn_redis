# 爱好词表阅读样板（guide）

词表本体在上一级：`lexicon.json` / `lexicon.md` / `lexicon.jsonl`。那些文件是机器可读的实践清单——叶子短、字段齐，但不适合一口气读。

这个目录是**给人翻的样板**：把一类叶子展开成带图的短文，说明圈子里实际在干什么、去哪找人。它不改词表，也不替代词表。

## 和词表的关系

| 词表字段 | 样板里怎么用 |
|---|---|
| `name_zh` / `path` | 页面标题和路径，文件名与叶子名一致 |
| `blurb` | 当种子，再写成可阅读的「这是什么」 |
| `keywords` | 埋进正文，方便对照检索 |
| `reference` | 保留，并补更贴实践的来源 |
| `circle_evidence` | 扩成「入门线索」：社群、课、店、局 |

硬规则没变：叶子是**人在玩的爱好**，不是百科实体。例如写「包饺子、养面种」，不写「饺子作为一种食物」。

## 怎么读

1. 先打开类目页，看分类边界（比如「品酒」在词表里专指葡萄酒，白酒/威士忌/黄酒各有叶子）。
2. 再点叶子。每页结构相同：
   - 1–2 张图（图注 + 来源）
   - 这是什么（人话）
   - 怎么玩 / 圈子里聊什么
   - 入门线索（可探的社群和场所类型）
   - 参考链接
3. 需要机器处理时，回到 `../lexicon.json`，用 `path` 对齐。

在 GitHub 上点进 `.md` 即可预览图片和链接，不必本地构建。

## 图片

优先热链 [Wikimedia Commons](https://commons.wikimedia.org/) 的缩略图，不往仓库塞大图。热链宽度用 Wikimedia 现行台阶（本样板用 960px），避免 800px 这类非台阶尺寸被拒。每张图都写了作者/许可和文件页。若要离线存档，请按 Commons 许可自行下载。
