# 无线电电子

技术与制作下的电波和电路亚类。4 片叶子：发、找、听、焊板。都按爱好写，发射必须持证合规。

## 边界

无线电三片，别混成一个「玩对讲机」：

- **[业余无线电](业余无线电.md)**：考证、设台、呼号、通联。要发射。
- **[短波收听](短波收听.md)**：只收不发，记日志、求广播 QSL。德生和 SDR 是主场。
- **[无线电测向](无线电测向.md)**：野外找隐蔽信标，腿和方向图比话筒重要。

电路一片：

- **[电子制作](电子制作.md)**：烙铁、面包板、单片机小制作。金属架子上的电焊去 **[焊接爱好](../动手技艺/焊接爱好.md)**。
