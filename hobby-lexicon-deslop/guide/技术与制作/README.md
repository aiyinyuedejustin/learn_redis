# 技术与制作

词表大类。15 片叶子：四片在扳手和焊枪旁，七片围着桌面机器和遥控飞行器，四片守着电波和电路板。

这里不写「数控机床史」「无线电原理课」。写的是人怎么在创客空间排队用激光、怎么约一场穿越机局、HAM 群在吵哪场 A 类考试。重叠很正常——焊铁架子的人也在电子制作圈晃，穿越机飞手和航模场常抢同一片空域。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看三个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [数字制造](数字制造/README.md) — 打印、切削、激光、遥控飞行
- [动手技艺](动手技艺/README.md) — 焊、扳手、改装、锁具
- [无线电电子](无线电电子/README.md) — 通联、测向、短波、电路板

## 阅读提示

无线电发射、无人机飞行、机动车改装都按**爱好、合法、合规**写。无证发射、禁飞区起飞、擅自改变机动车登记结构不在范围内。开锁只写锁具结构与收藏，不写开锁手法。图片全部热链 Wikimedia Commons，图注里有文件页。
