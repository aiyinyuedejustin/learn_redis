# 动手技艺

技术与制作下的扳手亚类。4 片叶子：焊、拧、改、看锁。都是「自己下手」，不是「工厂工种」。

## 边界（避免看成百科词条）

- **[焊接爱好](焊接爱好.md)** 是金属熔化连接：电焊、氩弧、小架子和小件。电路板上的烙铁去 **[电子制作](../无线电电子/电子制作.md)**。
- **[自行车改装](自行车改装.md)** 是保养、换组、扳手圈；死飞是其中一支，不是全部。
- **[汽车改装爱好](汽车改装爱好.md)** 专指合法范围内的外观/轮毂/包围交流和车友会，不是无手续改结构。
- **[开锁兴趣](开锁兴趣.md)** 写锁具结构和收藏。只谈自己的锁和公开结构图，不写开锁手法。
