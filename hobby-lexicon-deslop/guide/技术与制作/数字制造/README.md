# 数字制造

技术与制作下的机器和遥控亚类。7 片叶子：三台桌面设备，四类遥控飞行/模型。都按爱好写，不按工厂岗位写。

## 边界

桌面三件套常挤在同一间创客空间，别混成一个「数控」：

- **[3D打印](3D打印.md)**：热熔堆叠，切片和第一层。
- **[CNC爱好](CNC爱好.md)**：刀具切削，CAM、吃刀和夹具。
- **[激光雕刻](激光雕刻.md)**：光切木板和亚克力，防火和材料表。

天上四片，词表分得很开：

- **[无人机航拍](无人机航拍.md)**：消费级带云台，构图和适飞空域。
- **[无人机竞速](无人机竞速.md)**：穿越机、眼镜、计时赛。
- **[航模飞行](航模飞行.md)**：固定翼和传统飞场，目视遥控是主轴；穿越机只是邻居。
- **[遥控模型](遥控模型.md)**：车、船、以及「遥控器本身」这一层，飞机只是其中一支。
