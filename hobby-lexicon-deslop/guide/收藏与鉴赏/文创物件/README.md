# 文创物件

收藏与鉴赏下的「当代物件」亚类。8 片叶子：二次元柜子、腕表抽屉、笔袋、碟架、古着袋。都按爱好写，不按代购和炒货写。

## 边界

二次元三片，别混成一个「买谷」：

- **[谷子收藏](谷子收藏.md)**：吧唧、色纸、立牌、痛包，小件周边。
- **[徽章收藏](徽章收藏.md)**：纪念章、襟章、谷子吧唧——别针和章体本身。
- **[手办收藏](手办收藏.md)**：景品、比例尺、粘土人，要占柜子体积的那一类。

其余五片各自成圈：

- **[手表收藏](手表收藏.md)**：机械表和表友局，不是商场导购。
- **[淘古着](淘古着.md)**：动手挑旧衣服，不是「vintage 穿搭账号」。
- **[漫画单行本收藏](漫画单行本收藏.md)**：版本和书况；看漫画剧情是另一件事。
- **[钢笔收藏](钢笔收藏.md)**：笔尖和墨水，写得出字才算玩起来。
- **[黑胶唱片收藏](黑胶唱片收藏.md)**：碟和听感。听音乐的大类里另有唱片叶，这里盯的是藏和转。
