# 自然标本

收藏与鉴赏下的「从地里和海里来」的亚类。3 片叶子：化石、矿物晶体、海贝。都按标本集藏写，不按挖宝攻略写。

## 边界

- **[化石收藏](化石收藏.md)**：有生物年代的石头。三叶虫、菊石是入门常见货。
- **[矿物标本收藏](矿物标本收藏.md)**：晶体、晶簇、产地标签。化石里的矿化可以串门，圈子仍是两拨人。
- **[贝壳收藏](贝壳收藏.md)**：现生海贝和螺，不是古生物。海边捡要问保护区，商店货要问来路。

三片都要求：**合法流通、能说出来源**。保护区采挖、海龟类等受保护物种，不在爱好范围内。

## 叶子

1. [化石收藏](化石收藏.md)
2. [矿物标本收藏](矿物标本收藏.md)
3. [贝壳收藏](贝壳收藏.md)

线上常见落点：化石吧、矿物标本吧、贝壳收藏吧、地学科普群。线下是地质博物馆商店、矿物展、化石展、海边合法采集点——博物馆比摊位故事可靠。
