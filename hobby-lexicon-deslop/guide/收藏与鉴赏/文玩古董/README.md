# 文玩古董

收藏与鉴赏下的器物亚类。6 片叶子：闻、刻、摸、养。都按上手鉴赏写，不按拍卖行估价写。

## 边界

茶席两片，别并成「买茶具」：

- **[紫砂壶收藏](紫砂壶收藏.md)**：泥料、壶型、宜兴窑口，要开汤养。
- **[茶宠把玩](茶宠把玩.md)**：浇茶出包浆的小件。常和壶一起买，圈子不完全重合。

其余四片：

- **[习香道](习香道.md)**：品香和香席。制香在手作大类，这里是闻和仪。
- **[印章收藏](印章收藏.md)**：印石、印谱、名家印。自己操刀是「练篆刻」，在手作里。
- **[玉石鉴赏](玉石鉴赏.md)**：料、工、把玩，和田玉出现频率最高。
- **[古董鉴赏](古董鉴赏.md)**：最大的筐——瓷、铜、木器、杂项。玉、印、壶都可能从这里分岔出去，但这片叶子谈的是器物交流和眼力，不是单开一门。
