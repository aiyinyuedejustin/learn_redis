# 纸品票证

收藏与鉴赏下的纸质亚类。7 片叶子：写过、印过、盖过戳、坐过车的那一张。都按集藏写，不按投资课写。

## 边界

片和邮容易缠在一起：

- **[明信片收藏](明信片收藏.md)**：按专题、年代、出版社收，抽屉里排好。
- **[Postcrossing](Postcrossing.md)**：平台随机互换，重点是寄出和等回信，不是把一张卡片养到品相满分。
- **[集邮](集邮.md)**：邮票、邮戳、邮册、邮展。明信片上的票可以进邮集，但叶子不同。

其余四片：

- **[图书收藏](图书收藏.md)**：版本、藏书票、装帧；读书笔记不是这片的作业。
- **[地图收藏](地图收藏.md)**：古今地图和测绘印刷品。
- **[票根收藏](票根收藏.md)**：电影票、车票、门票，日子印在纸上。
- **[钱币收藏](钱币收藏.md)**：古钱、机制币、纸币。硬币是金属，仍跟票证一起出现在钱币学会里。
