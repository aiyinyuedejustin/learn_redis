# 收藏与鉴赏

词表大类。25 片叶子：柜子、口袋、茶席和标本盒里的东西，人怎么找、怎么藏、怎么跟同好吵真假。

这里不写「邮票史」「玉的矿物学」。写的是人怎么补一套生肖票、怎么在古着店摸面料、怎么把一饼紫砂养出包浆。重叠很正常——痛包上的吧唧也算徽章，茶宠常和紫砂壶一起买，化石摊旁边往往就是矿物。遇到跨界，叶子页会互相指一下。
