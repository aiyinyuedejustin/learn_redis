# 牌类

棋牌与益智下的牌桌亚类。5 片叶子，都是「坐下来打一局」。麻将用牌张，其余多用扑克牌；花切手法不在这里，见 [花切扑克](../益智解谜/花切扑克.md)。

## 边界

- **[打麻将](打麻将.md)** 是国标和地方规则麻将。先问「打哪种」，再入局。
- **[打桥牌](打桥牌.md)** 是定约桥牌：叫牌、定约、打牌。不是升级，也不是干瞪眼。
- **[打升级](打升级.md)**（拖拉机）和 **[掼蛋](掼蛋.md)** 都是四人两两一伙的升级系。掼蛋是近年更常见的变体，规则和进贡不要混用。
- **[玩扑克](玩扑克.md)** 词表里主要指德州等**牌技**娱乐，按守法自娱写。赌场、赌资、出千不在范围内。
