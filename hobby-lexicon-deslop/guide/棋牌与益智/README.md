# 棋牌与益智

词表大类。24 片叶子：棋盘上的对局、牌桌上的伙牌、以及不靠对手也能练的解谜。

这里不写「围棋史」「麻将起源」。写的是人怎么约一盘、怎么记谱、去哪找局。重叠很正常——玩扑克的人也可能在花切，万智牌玩家同时泡在集换式卡牌店。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看四个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [棋类](棋类/README.md) — 围空、杀将、暗棋、骰子棋
- [益智解谜](益智解谜/README.md) — 魔方、数独、填字、拼图、密室、花切
- [桌游卡牌](桌游卡牌/README.md) — 开盒约局、机制设计、TCG 与剧本杀
- [牌类](牌类/README.md) — 麻将、桥牌、升级、掼蛋、扑克（牌技，守法）
