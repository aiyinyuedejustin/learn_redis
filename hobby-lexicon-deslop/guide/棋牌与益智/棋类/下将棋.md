# 下将棋

`棋牌与益智/棋类/下将棋` · Shogi

词表种子：将棋对局与定迹学习。和中国象棋只是远亲，持驹规则完全不是一回事。

## 这是什么（人话）

日本将棋：子被吃进「持驹」，再打到几乎任意空格。圈子里学的是定迹（开局套路）、攻防速度、以及何时打入。国内玩的人不多，但吧和线下小局稳定存在——别用象棋的术语去套，会立刻露馅。

## 怎么玩 / 圈子里聊什么

- 居飞车还是振飞车，美浓围还是矢仓。
- 打入的位置，二步、打步诘这些禁手。
- 棋谱软件和日本网站，中文资料相对薄。
- 和象棋爱好者互相安利时，最常卡在「凭什么能把子打回来」。

将棋吧、日式棋类圈、少数城市的日本文化活动是入口。线上 81Dojo、Shogi Wars 能找到对手；线下常是三五人的定期面棋，偶尔挂在桌游店或日语角旁边。别指望公园里有现成的将棋摊。

## 入门线索

- 线上：将棋吧、日式棋类群、英文/日文入门站的中文笔记。
- 线下：同城面棋局、日语角或桌游店的主题夜（有则珍惜）。
- 起点：先会走子、升变和打入，再碰定迹。一副入门将棋比打印纸棋盘有用。
