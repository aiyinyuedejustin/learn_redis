# 棋类

棋牌与益智下的棋盘亚类。8 片叶子，都是「自己坐下来下一盘」，不是棋具鉴赏或棋史考证。

## 边界（避免看成百科词条）

- **[下围棋](下围棋.md)** 是围空和死活；别和五子棋共用一张 19 路棋盘就当成同一圈子。
- **[下象棋](下象棋.md)** 专指中国象棋。国际象棋、将棋各有叶子。
- **[下国际象棋](下国际象棋.md)** 是 chess：王车易位、等级分、棋院周末赛。
- **[下将棋](下将棋.md)** 是日本将棋：吃子进持驹、再打回盘上。国内圈子小，别和象棋混称「日本象棋」就完事。
- **[下五子棋](下五子棋.md)** 连五为胜；认真下的人会碰到**连珠**禁手和开局交换。
- **[下军棋](下军棋.md)** 是二人暗棋（陆战棋）。**[下四国军棋](下四国军棋.md)** 是四人联盟，棋盘和沟通方式都不同。
- **[下双陆棋](下双陆棋.md)** 带骰子，常出现在桌游吧，不太出现在公园棋摊。
