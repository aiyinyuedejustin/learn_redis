# 益智解谜

棋牌与益智下的单人（或合作）解谜亚类。6 片叶子：有的对着纸，有的对着房间，有的对着一副牌。都按「自己在练」写，不按世界纪录写。

## 边界

- **[玩魔方](玩魔方.md)** 是速拧和异形；复原公式可以背，圈子聊的是手法和成绩。
- **[玩数独](玩数独.md)** 是填数盘和变体，不是「脑筋急转弯合集」。
- **[填字游戏](填字游戏.md)** 是中英文格子谜，线索和词库才是日常。
- **[拼图爱好](拼图爱好.md)** 是纸质拼图的拼、藏、换，不是 App 里滑块。
- **[玩密室逃脱](玩密室逃脱.md)** 是进主题房间解机关。和 [剧本杀](../桌游卡牌/剧本杀.md) 常被店家排在一起，玩法不是同一套。
- **[花切扑克](花切扑克.md)** 是手法和牌花。打牌去 [玩扑克](../牌类/玩扑克.md)；花切圈一般不谈牌力。
