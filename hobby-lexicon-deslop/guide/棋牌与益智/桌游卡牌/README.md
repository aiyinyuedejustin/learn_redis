# 桌游卡牌

棋牌与益智下的现代桌面与扮演亚类。5 片叶子：开盒约局、自己做一款、集换对战、进店玩本。都按爱好写，不按发行商岗位写。

## 边界

别把「桌游」收成一个筐：

- **[玩桌游](玩桌游.md)**：现代桌面游戏开盒、学规则、约局。德式、美式、派对游戏都从这里进。
- **[桌游设计](桌游设计.md)**：业余做机制、打样、拉人试玩。玩得多不等于在设计。
- **[万智牌](万智牌.md)**：Magic: The Gathering 的构筑和指定店赛。它是 TCG 的一片，不是全部。
- **[集换式卡牌](集换式卡牌.md)**：TCG 通称——集换、组套、店赛。游戏王、宝可梦卡牌等落在这里，万智牌另有专叶。
- **[剧本杀](剧本杀.md)**：线下剧本推理扮演，有 DM、有本。和 [玩密室逃脱](../益智解谜/玩密室逃脱.md) 常在同一商圈，不是同一叶子。

传统棋类、麻将、扑克不在这亚类，见 [棋类](../棋类/README.md)、[牌类](../牌类/README.md)。
