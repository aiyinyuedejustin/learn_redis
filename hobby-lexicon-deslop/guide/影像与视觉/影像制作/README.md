# 影像制作

影像与视觉下的活动影像亚类。4 片叶子，都是「拍完还要剪」，不是「看电视」。

## 边界

视频四片，别揉成一个「自媒体」：

- **[摄像创作](摄像创作.md)**：视频拍摄和剪辑表达，器材和镜头语言更重。活动纪录、短片素材、自己练手都算。
- **[拍Vlog](拍Vlog.md)**：第一人称生活记录。对着镜头说话、日更或周更，成片比电影短、比平台短视频长。
- **[短视频创作](短视频创作.md)**：给平台节奏的短片。竖屏、前几秒、字幕和BGM 是日常话题。
- **[电影制作](电影制作.md)**：短片当一条片子做——编剧、分镜、拍摄、成片。独立影像社群是主场，不是院线工业流程。

和摄影亚类的重叠在「会用相机」。这边多了时间轴、声音和叙事；静帧后期请回 [摄影](../摄影/摄影.md)。

## 叶子

1. [摄像创作](摄像创作.md)
2. [拍Vlog](拍Vlog.md)
3. [短视频创作](短视频创作.md)
4. [电影制作](电影制作.md)

线上常见落点：摄像师吧、Vlog 创作圈、短视频创作者群、独立影像社群。线下是器材店体验、高校影像社、城市短片放映和独立影展征片——卖相机的店可以当入口，叶子本身仍是业余实践。
