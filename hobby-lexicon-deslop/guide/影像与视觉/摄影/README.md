# 摄影

影像与视觉下的取景亚类。8 片叶子，都是「自己按快门」，不是「研究摄影史」。

## 边界（避免看成百科词条）

- **[摄影](摄影.md)** 是最大的筐：相机、曝光、焦段、RAW 后期。人像、风光、街拍都从这里分岔出去。
- **[人像摄影](人像摄影.md)** 管棚拍外拍和布光；被摄者通常知情。**[街头摄影](街头摄影.md)** 管扫街抓拍，伦理和构图捆在一起。
- **[风光摄影](风光摄影.md)** 是脚架和日出机位；**[航拍摄影](航拍摄影.md)** 是无人机空中视角，必须合规。
- **[胶片摄影](胶片摄影.md)** 走化学和冲洗店；数码后期再强也替不了等胶卷的那几天。
- **[天文摄影](天文摄影.md)** 是星空 / 深空和赤道仪，和夜景风光只在「天黑出门」这点重叠。
- **[手机摄影](手机摄影.md)** 不装相机门禁。计算摄影和后期 App 是主业，单反不是门槛。
