# 平面与字

影像与视觉下的字与版式亚类。4 片叶子：网格上的设计，纸上的毛笔和钢笔，墙上的合法涂鸦。

## 边界

四片别混成一个「视觉艺术」：

- **[平面设计](平面设计.md)**：版式、字体、网格，爱好向练手和作品圈。不是岗位说明书。
- **[练书法](练书法.md)**：毛笔临帖、笔会。公园水写是入口，宣纸日课才是主业。
- **[练硬笔书法](练硬笔书法.md)**：钢笔、中性笔，字帖和结构。和毛笔共用「结字」，器具和考级路线不同。
- **[街头涂鸦](街头涂鸦.md)**：合法墙、授权墙绘。乱喷公共设施不在这片叶子里。

书法两片和绘画亚类的 [画国画](../绘画/画国画.md) 常是同一批人，但叶子按「写字」还是「画画」拆。涂鸦和平面设计也会抢字体话题，墙和印刷品仍是两场。
