# 绘画

影像与视觉下的动手画画亚类。8 片叶子，都是「自己下笔」，不是「参观美术馆」。

## 边界（避免看成百科词条）

- **[画素描](画素描.md)** 是造型底子：石膏、速写、明暗。很多人从画室起步，再分到别的叶子。
- **[画水彩](画水彩.md)**、**[画油画](画油画.md)**、**[画丙烯](画丙烯.md)** 按媒介拆。水彩盯水分，油画盯油性和干燥时间，丙烯干得快、厚堆方便。三块互相串门，圈子不全是同一群人。
- **[画国画](画国画.md)** 是笔墨纸砚：写意和工笔。和水彩都用水，但术语、纸和圈子都不同。
- **[数字绘画](数字绘画.md)** 是板绘 / CG 本身：图层、笔刷、数位屏。**[画插画](画插画.md)** 更在意一张图把叙事讲完，约稿和个人项目都算。**[画漫画](画漫画.md)** 管分镜和格子，不是单张插画拉长。
