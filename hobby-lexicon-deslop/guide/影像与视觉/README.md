# 影像与视觉

词表大类。24 片叶子：一半在取景框后面，一半在纸、屏和墙上。

这里不写「摄影史」「美术概论」。写的是人怎么约一场棚拍、怎么在画室抠石膏、合法墙上喷字、把周末短片剪完。重叠很正常——拍人像的人也扫街，板绘和插画常是同一只笔。遇到跨界，叶子页会互相指一下。

## 怎么逛

先看四个亚类的边界，再下钻叶子。想对照机器字段，用每页顶部的 `path` 去 [lexicon.json](../../lexicon.json) 里搜。

- [摄影](摄影/README.md) — 相机、胶片、星空、航拍、手机
- [绘画](绘画/README.md) — 素描到板绘，水彩油画国画漫画
- [平面与字](平面与字/README.md) — 版式、毛笔、硬笔、合法墙绘
- [影像制作](影像制作/README.md) — Vlog、摄像、短视频、短片

## 阅读提示

航拍按**合规飞行**写，涂鸦按**合法墙 / 授权墙绘**写。人像和街拍都涉及他人面容，叶子里会点到授权和分寸，不写怎么躲规则。图片全部热链 Wikimedia Commons，图注里有文件页。
